# 🎶 Mood-Based Music Recommendation System

## 📌 Overview
In today's fast-paced world, music plays a key role in shaping our emotions and enhancing our moods. This project, **Mood-Based Music Recommendation System**, recommends the **Top 10 songs** tailored to your current mood. Users can input their mood (or it can be detected using facial expressions or text inputs), and the system delivers personalized song recommendations.

The project includes a **working prototype** built using **Streamlit**, providing a simple, interactive interface where users can select their mood and instantly receive song recommendations.

## 🚀 Features
- 🎭 **Mood Detection Input**: Choose from predefined moods (Happy, Sad, Energetic, Calm, etc.)
- 📻 **Top 10 Song Recommendations**: Songs curated based on your selected mood.
- 💻 **Interactive Streamlit Interface**: Users can explore recommendations via a clean, user-friendly app.
- 📊 **Mood-Song Mapping**: Each mood is linked to a curated list of songs from multiple genres.
- 🎧 **Dynamic Experience**: Recommendations update based on mood selection changes.

## 🛠️ Technologies Used
- **Python** (for data processing and recommendation logic)
- **Streamlit** (for app interface and user interaction)
- **Pandas** (for data handling and analysis)
- **Machine Learning (optional)** (for mood classification if facial/text analysis is added in future versions)

## 📊 Dataset
- A curated dataset of songs across various genres and moods.
- Songs categorized into mood-based playlists (Happy, Sad, Relaxed, Energetic, Romantic, etc.)

## 📥 Installation & Setup

### 📋 Prerequisites
- Python 3.x
- Streamlit
- Pandas

### ⚙️ Steps
Clone the repository:
```bash
git clone https://github.com/your-username/mood_music_recommendation.git
cd mood_music_recommendation
pip install -r requirements.txt
streamlit run app/main.py
```

🌐 Usage
- Launch the Streamlit app.
- Select your current mood from the dropdown.
- View Top 10 personalized song recommendations tailored to your mood.
- Explore recommendations across genres or moods.
